# ChatGPT Website Projects

This repository contains website projects recovered from our ChatGPT build history and organized for GitHub.

## Websites included

1. **Backend Learning Lab**
   - Path: `backend-learning-lab/index.html`
   - Interactive backend/full-stack learning app with lessons, quizzes, and progress tracking.

2. **JavaScript Master Encyclopedia**
   - Path: `javascript-master-encyclopedia/index.html`
   - Visual JavaScript learning/reference website with examples, sections, tables, and diagrams.

3. **PipeCraft Pro** 🔧
   - Path: `pipecraft-pro/` (React + Vite + Tailwind — run `npm install && npm run dev` inside the folder)
   - Plumbing career simulator game: timed service calls with diagnosis/repair scoring, a training academy, a house rough-in build mode with code inspections, and a business management layer. See `pipecraft-pro/README.md`.

4. **What's in Your Water (WiYW) — Plumbing Marketing & Ops System** 💧
   - Path: `wiyw/` (FastAPI + Postgres backend, n8n workflows, Storyblok components, docs)
   - Full marketing/lead-management stack for a Palm Beach County water-treatment + plumbing brand: lead capture → booking confirmations → reminders → review requests → reactivation → local SEO. Backend is boot-tested; migrations verified. Start with `wiyw/CLAUDE.md`, then the 17-section handoff blueprint in `wiyw/docs/blueprint/`.
