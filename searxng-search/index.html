SearXNG Privacy Search

A front-end for SearXNG, the open-source metasearch engine that aggregates results from 70+ engines without tracking you, profiling you, or sharing your IP with third parties.

Instance:

Your query is sent directly to the SearXNG instance you choose and opens in a new tab. No query is stored on this page (your last-used instance is saved locally in your browser). Pick the instance you trust most, or run your own (see below).

Why SearXNG?

● No tracking

No cookies, no profiling, no ad-tech. Your searches aren't logged or sold, and your IP is never shared with the upstream engines.

● 70+ engines

Aggregates Google, Bing, DuckDuckGo, Wikipedia, GitHub, and dozens more into one ranked result list you can tune.

● Self-hostable

Free and open source (AGPL). Run it on your own server with Docker in minutes for total control.

● Categories

Search web, images, videos, news, maps, music, IT, and science — each backed by engines specialized for that content.

● No JavaScript needed

The result pages work without client-side scripts and offer a clean, lightweight, ad-free reading experience.

● Open API

Add &format=json on a self-hosted instance to build apps, bots, and automations on top of search.

Run your own instance

  1. Install Docker, then pull the official image: docker pull searxng/searxng
  2. Create a config folder and run it: docker run -d -p 8080:8080 -v "$PWD/searxng:/etc/searxng" searxng/searxng
  3. Open http://localhost:8080 and edit searxng/settings.yml to set a secret_key and pick your engines.
  4. Back here, choose Custom… above and paste your instance URL to search through your own private node.
